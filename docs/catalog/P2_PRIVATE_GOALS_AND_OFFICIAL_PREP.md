# P2b — Private Goals and Issuer-Hosted Preparation Links

**Started:** October 12, 2026. **Scope:** first ten reviewed identity-only destinations from the [P2 issuer directory](P2_ISSUER_VERIFIED_DIRECTORY.md), with eight separately reviewed *outbound* preparation/reference links.

## Why this phase

People can now browse ten source-reviewed credentials/exams. A link is useful but not equivalent to being able to make that item a personal learning goal. Conversely, linking to an external issuer must not turn the learner's private study plan into an *official* credential or claim that the app contains that issuer's exams.

## Implementation

- `supabase/migrations/20261012000004_catalog_destination_resources_goal_links.sql`: additive, RLS-protected `catalog_destination_goal_links` and `catalog_destination_resources`.
- A learner can insert/read/delete a **single source identity link for a goal they own**; RLS additionally checks the draft is private, unreviewed and **matches the catalog type exactly**. It cannot point to another learner's goal or a retired credential.
- A source link never changes the goal's `is_official=false`, `review_status='unreviewed'`, `status='draft'`, or grants access to restricted exam/course content.
- The app's `CreateTargetDialog` suggests reviewed destination names and issuers and records the stable issuer source identity when a user submits their private goal. The app reports an error if the goal was created but its source link failed; it does **not** imply source binding succeeded.
- `professional_license` currently has no corresponding `TargetType`. **Do not mislabel a Florida real estate license as an exam or certification.** Its official link is still browseable, but the goal action is not available until a true license target type is introduced.
- `catalog_destination_resources` exposes **issuer-owned URLs only** for current published destinations. If a source destination is retired, the accompanying resources disappear from public queries automatically through parent-scoped RLS.
- `data/catalog/official_preparation_links_2026_10.json` contains eight reviewed external resources (Microsoft exam study guides, AWS cloud fundamentals learning plan, PMI exam preparation options, NCSBN test plans) and `tool/catalog_p2_resources.py` validates and renders reproducible SQL.
- The taxonomy explorer gains **Issuer study links** and **Create private goal** actions for supported credential types. Offsite links open in the browser with copy-link fallback. This is not an enrollment action; access and costs depend on the source.
