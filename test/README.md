## 🔧 Troubleshooting

### **Common Issues:**

#### **Hive Initialization Errors:**
```bash
LateInitializationError: Field '_lessonBox' has not been initialized
```
**Solution**: Use `test_helper.dart` to properly initialize test environment

#### **Supabase Instance Errors:**
```bash
You must initialize the supabase instance before calling Supabase.instance
```
**Solution**: Mock Supabase client or use test initialization

#### **Mock Generation Issues:**
```bash
Missing mocks or outdated mocks
```
**Solution**: Run `flutter packages pub run build_runner build`

### **Best Practices:**
1. **Use Test Helper**: Always initialize test environment properly
2. **Mock External Services**: Don't rely on real API calls in tests
3. **Clean Up**: Ensure proper cleanup after tests
4. **Isolated Tests**: Each test should be independent
5. **Clear Naming**: Use descriptive test names and group organization
